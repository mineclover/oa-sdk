"@oa-sdk/popup-bridge": minor
---

Add `@oa-sdk/popup-bridge`: an origin-verified popup handshake (HELLO / CONNECT / READY over `postMessage` + `MessageChannel`), a symmetric JSON-RPC 2.0 endpoint with cancellation, timeouts and idempotency keys, contract-first type declarations (`defineContract`, `method`, `event`, `definePopup`), and RPC generation utilities (`createRpcApi`, `createMethodCaller`, `HandlerRegistry`) shared by the host SDK, the popup runtime and in-memory test doubles. It also covers popups that open popups: a shared bridge node with peer links for both neighbours, attention requests (`focus`, title blink, system notification, in-page toast) that the receiving page turns into effects by its own policy and acknowledges when the user returns, topology and trace inspection, and revisioned shared state with optimistic writes. Peers advertise optional protocol features in the handshake and use only the intersection (`events.replay`, `events.coalesce`; unknown or absent features fall back to the baseline wire behaviour), a bounded per-event replay buffer lets a subscriber recover missed events through `bridge.replay` and falls back to `gap` when the buffer no longer covers the range (a reloaded popup page is reported as a reset), high-frequency events can be coalesced within a window (`latest` or a reducer) with revisions and `missed` accounting kept consistent, and popup HELLO and host resubscribe retry with bounded exponential backoff and jitter that is cancellable, observable (`retry` events) and driven by an injectable clock.
